View GitHub Repository Read Documentation

Mission Overview

Software simulation for resilient deep-space communication.

What is ORBIT-GUARD?

ORBIT-GUARD simulates an intelligent planetary probe communication system. The system observes probe conditions, identifies possible communication failures, evaluates the situation, selects recovery actions, and attempts to restore communication with Earth.


The project demonstrates how autonomous decision-making can improve spacecraft communication resilience when direct communication is interrupted or degraded.

Core Objective

Detect communication problems early and intelligently recover the communication link while preserving mission data and maintaining reliable two-way communication.


The simulation provides a safe environment for testing mission failures and recovery strategies without requiring real spacecraft hardware.

Key Capabilities

Core functions demonstrated by the ORBIT-GUARD simulation.

🛰️

Probe Monitoring

Continuously represents probe status, mission conditions, communication state, storage and operational parameters.

📡

Communication Recovery

Simulates detection and recovery of communication failures between the planetary probe and Earth.

🧠

Intelligent Diagnosis

Evaluates observed conditions and identifies possible causes of communication degradation or failure.

🔄

Two-Way Communication

Models communication in both directions between the spacecraft and the Earth station.

⚠️

Fault Simulation

Allows different mission and communication faults to be represented and tested inside the simulation.

📊

Mission Visualization

Provides a Streamlit dashboard for observing mission state, communication events and recovery behaviour.

System Architecture

High-level flow of the ORBIT-GUARD simulation.

1. Probe Generates mission data and system status.
2. Observation Monitors communication and mission conditions.
3. Diagnosis Analyzes failures and determines possible causes.
4. Recovery Selects and executes communication recovery actions.
